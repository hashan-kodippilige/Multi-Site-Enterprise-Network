# Multi-Site Enterprise Network with VPN and OSPF

## Project Overview

Designed and implemented a multi-site enterprise network connecting two company locations and an R&D annex through secure VPN tunnels.

## Technologies Used

- Cisco IOS
- Cisco ASA Firewalls
- OSPF
- Site-to-Site VPN
- VLANs
- EtherChannel
- DHCP
- PAT
- NTP
- SSH

## Architecture

### Site 1

- Marketing Department
- Operations Department
- Management Department

### Site 2

- Business Department
- Management Department

### Annex

- R&D Department

## Security Features

- Site-to-Site IPsec VPN
- Cisco ASA Firewalls
- ACL Enforcement
- DMZ Web Services
- SSH Administration

## Routing

- OSPF Dynamic Routing
- Inter-VLAN Routing
- NAT/PAT
